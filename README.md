# 文件自动整理器

## 功能

这个程序可以根据文件扩展名，整理安全测试目录中的文件。

当前功能：

- 接收用户输入的目录路径；
- 检查路径是否存在；
- 检查路径是否为目录；
- 扫描目录中的直接文件；
- 根据扩展名进行分类；
- 自动创建分类目录；
- 移动文件到 `整理结果`；
- 支持大小写扩展名；
- 目标文件同名时跳过；
- 处理部分权限和文件不存在错误。

## 文件分类

| 扩展名 | 分类 |
| --- | --- |
| `.pdf`、`.PDF` | PDF |
| `.jpg`、`.png` | 图片 |
| `.xlsx` | Excel |
| 其他扩展名 | 其他 |
